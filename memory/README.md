# Project memory

Agent-maintained project memory. Read at session start when continuing work; update before ending a turn that changes tasks, decisions, or progress.

| File | Role |
|---|---|
| [`TASKS.md`](TASKS.md) | Goals and subtasks: who added them, when, and how we aim to fulfill them |
| [`QA.md`](QA.md) | Append-only questions and answers between user and agent |
| [`WORKLOG.md`](WORKLOG.md) | Append-only dated notes on what happened |
| [`FUTURE.md`](FUTURE.md) | Parked ideas; only when user asks about future plans |

Do not rewrite past WORKLOG or QA entries; correct via a new entry. TASKS may be updated in place for status/subtask checkboxes.
