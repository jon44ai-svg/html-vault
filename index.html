      About HTML Vault

      HTML Vault stores Files and Bundles in this browser’s local storage. Data stays on this device unless you export or share it.

      • Import HTML/JSX/CSS/JS/JSON/text, images, or a ZIP. Multi-file project ZIPs become Bundles. Export one File, the active Bundle, or a full ZIP with history.
      • Image caps: 512 KiB per image; 2 MiB total images per Bundle. Oversized imports are refused with a toast.
      • Changes auto-save. Use Checkpoint to make a labeled history snapshot.
      • Compile validates HTML or transforms JSX/TSX and runs it in a sandboxed Preview.
      • Use Copy logs to copy preview console messages and errors for debugging.
      • Use the Insert ▼ button (or Ctrl/⌘+Shift+V in the editor) to insert clipboard content at the cursor, append it to the end, replace the selection, or split multiple HTML documents from the clipboard into separate files.
      • Browser storage has limited capacity. Export backups regularly.
